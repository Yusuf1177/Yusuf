1Eksperimen 10 + 20

let a = "10";
let b = "20";
console.log(a + b);
Apa output program?
1020
Mengapa hasil tersebut terjadi?

Karena a dan b berisi teks (String), tanda + menggabungkan teks, bukan menjumlahkan angka.

Apakah a dan b bertipe Number?
Bukan, keduanya bertipe String karena ditulis dalam tanda kutip.
Uji sekarang. Apakah prediksimu benar?

Benar. Setelah dijalankan, hasilnya 1020, bukan 30.

Tekan “Jalankan kode”.

2Menemukan tipe data

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
VariabelPrediksiHasil typeofKesimpulan

Temuan: apa perbedaan String dan Number?

String adalah data teks yang ditulis dengan tanda kutip dan tidak bisa dihitung secara matematis. Number adalah angka tanpa kutip yang bisa dijumlah, dikurang, dikali, dan dibagi.

Tekan “Jalankan kode”.

3Konversi String menjadi Number

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil);
Isian: let hasil =
Number(a) + Number(b);

30

Algoritma saya

  1. Minta input nilai tugas, UTS, dan UAS dengan prompt().
  2. Ubah ketiga input menjadi Number dengan Number().

H. Think — Pair — Share

Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Karena prompt() selalu menghasilkan String. Tanpa konversi, operator + akan menggabungkan teks, bukan menjumlahkan angka.

Apa perbedaan "10" dengan 10?

"10" adalah String (teks), sedangkan 10 adalah Number (angka) yang bisa dihitung.

Apa yang terjadi jika lupa Number()?

Hasil perhitungan salah. Contohnya "10" + "20" menjadi "1020", bukan 30.

Pair: bandingkan jawaban dengan teman

Intinya sama, hanya susunan kalimat yang berbeda karena setiap orang memakai kata-kata sendiri.

Share: temuan penting untuk kelas

Hasil prompt() selalu String, jadi bungkus dengan Number() sebelum menghitung.
