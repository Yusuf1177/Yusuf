3. Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
let umur = prompt("Masukkan umur:");
console.log(umur);
Fungsi prompt(): menampilkan kotak dialog untuk meminta pengguna mengetik data. Data yang diketik disimpan ke dalam variable (berupa teks/string) dan bisa dipakai di program.

4. Menghitung Umur

let tahunLahir = prompt("Masukkan tahun lahir:");
let tahunSekarang = 2026;
let umur = tahunSekarang - tahunLahir;
console.log(umur);
Contoh: tahun lahir 2009, maka umur = 2026 - 2009 = 17 tahun. (Isi dengan tahun lahirmu sendiri di kalkulator bawah.)

8. Debugging

let harga = 5000;
let jumlah = 3;
let total harga = harga * jumlah;
console.log(total harga);
Kesalahan: Nama variable "total harga" memakai spasi. Nama variable tidak boleh mengandung spasi sehingga terjadi SyntaxError.
Perbaikan kode:
let harga = 5000;
let jumlah = 3;
let totalHarga = harga * jumlah;
console.log(totalHarga); // 15000

9. Kalkulator Tabungan

let uangAwal = Number(prompt("Uang awal:"));
let hari1 = Number(prompt("Tabungan hari pertama:"));
let hari2 = Number(prompt("Tabungan hari kedua:"));
let hari3 = Number(prompt("Tabungan hari ketiga:"));
let total = uangAwal + hari1 + hari2 + hari3;
console.log("Total tabungan = Rp", total);
Contoh: 50000 + 5000 + 7000 + 6000 → Total tabungan = Rp 68.000. Number() dipakai agar nilai dijumlahkan sebagai angka, bukan digabung sebagai teks.
